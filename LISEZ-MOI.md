# Chronogramme V3 · Galerie illustrée

Toutes les fonctions V3 et les 51 enquêtes originales sont conservées. Une nouvelle galerie illustrée avec filtres par classe est accessible depuis l'accueil ; elle permet de consulter les 51 couvertures V3 et d'ouvrir chaque histoire.

La fresque `assets/galerie/fresque-du-temps.webp` est un panorama thématique artistique : **elle ne correspond pas une à une aux 51 enquêtes**. Les 51 couvertures propres à chaque histoire restent sous `assets/posts/p1.webp` ... `p51.webp`.

## Installation GitHub Pages

Extraire le ZIP puis copier **index.html et tout le dossier assets** à la racine du dépôt Chronogramme. Ne pas effacer les autres fichiers ni remplacer seulement index.html. Cette version fonctionne sans compte et conserve les sauvegardes locales.

## État de publication

Le code de la galerie peut être poussé séparément. La fresque panoramique ne sera visible qu'une fois son fichier WebP transféré dans le dépôt au chemin indiqué.
