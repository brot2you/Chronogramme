# CHRONOGRAMME V2 — L’enquête historique

Application HTML autonome pour collège, compatible GitHub Pages, sans comptes, sans serveur.

## Installer / publier
1. Décompresser le ZIP.
2. Dans le dépôt GitHub de Chronogramme, remplacer `index.html` à la racine par ce fichier.
3. Conserver le dossier `index.html` à la racine, sans sous-dossier supplémentaire.
4. Valider (Commit) et attendre la publication automatique de GitHub Pages.

## Nouveautés V2
- 51 enquêtes originales conservées.
- Frise chronologique interactive, avec un accès direct aux enquêtes.
- 12 fiches « leçon minute » par niveau, ciblant des repères clés des programmes.
- 3 défis : chronologie, dates mystères, Brevet express (3e).
- 6 badges, records et statistiques de défis dans le carnet.
- Export et import de la progression JSON.
- Mise en page mobile améliorée, thème sombre et accessibilité maintenus.

## Sauvegarde et vie privée
La progression reste dans le localStorage du navigateur (clé `chronogramme:v1`, conservée pour ne pas perdre les résultats V1). Une exportation JSON permet de transférer la progression sur un autre appareil. Aucune connexion ni donnée utilisateur transmise par l’application.

## Notes pédagogiques
Les posts sont des témoignages fictifs pour travailler l’enquête historique et la critique des sources. Les fiches et les défis offrent des supports de révision et ne remplacent pas le cours. Brevet express ne constitue pas un sujet officiel du DNB.
